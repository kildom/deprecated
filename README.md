# Experimental Project using EV3Dev and Python

## Overview
This project is an experimental setup using the EV3Dev platform for LEGO Mindstorms and Python programming. The goal is to explore the capabilities of EV3Dev and create innovative robotics projects.

## Notes
- MicroSD card with EV3Dev\
  https://www.ev3dev.org/downloads/ \
  https://www.ev3dev.org/docs/programming-languages/ \
- EV3Dev Python library \
